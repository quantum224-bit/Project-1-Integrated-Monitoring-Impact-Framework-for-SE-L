# Project-1-Integrated-Monitoring-Impact-Framework-for-SE-L

### Project Overview

This project is designed to monitor school infrastructure and measure the impact of educational interventions. It uses data to rank schools and track student participation.

### Data Sources

* **Main Infrastructure Data:** The primary dataset `UDISE_plus-16-17_infra_kanpur_dehat_up.csv` is sourced from [Data.gov.in](https://www.data.gov.in/resource/number-schools-availability-infrastructure-and-facilities-school-management-and-2786).
* **Supportive Data:** Files like `Attendance_Baseline_2023_v2.csv` and `Attendance_Endline_2025_v2.csv` are dummy datasets created for testing the impact assessment logic.

### Folder Structure

* **`data_files/`**: Contains all raw CSV datasets used for analysis.
* **`scripts/`**: Contains the Python code for processing and analysis.
* **`generated_reports/`**: Contains the final Excel reports and visualization charts generated by the scripts.

### Script Descriptions

1. **`Assessment_system.py`**: Analyzes school facilities and assigns performance grades (A, B, or C).
2. **`kpi_monitoring.py`**: Tracks key performance indicators like water, electricity, and toilet availability across schools.
3. **`Impact_Assessment.py`**: Compares baseline and endline data to measure the 20% improvement in student attendance.

### How to Run

1. **Step 1:** Download or clone this repository to your computer.
2. **Step 2:** Ensure all data files are inside the `data_files/` folder.
3. **Step 3:** Open the scripts and update the file directory path to match your local folder location if necessary.
4. **Step 4:** Run the scripts in your Python environment.
5. **Step 5:** Check the `generated_reports/` folder for the final output files and charts.
